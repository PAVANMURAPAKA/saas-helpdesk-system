DMGT Unit 2: Relations, Poset & Equivalence Partitioning

Discrete Mathematical Relations & Hierarchy Verification

Formal verification of the support hierarchy Poset (Reflexive, Antisymmetric, Transitive) and disjoint category equivalence partitioning.

1. Reflexivity Proof

∀ a ∈ S, (a, a) ∈ R

Every agent tier inherently possesses resolution authority equal to itself. L1 ≤ L1, L2 ≤ L2, L3 ≤ L3, Lead ≤ Lead. Verified True.

2. Antisymmetry Proof

(a, b) ∈ R ∧ (b, a) ∈ R ⇒ a = b

If Agent A escalates to Agent B and Agent B can escalate to Agent A, they must belong to the exact same tier. Eliminates circular deadlocks.

3. Transitivity Proof

(a, b) ∈ R ∧ (b, c) ∈ R ⇒ (a, c) ∈ R

If L1 ≤ L2 and L2 ≤ L3, then L1 transitively possesses an escalation pathway to L3. Forms valid partially ordered set (Poset).
