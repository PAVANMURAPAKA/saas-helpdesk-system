$$\sigma_{\text{status} = 'Escalated' \land \text{priority} \in \{'High', 'Critical'\}}(\text{Tickets})$$
SELECT * FROM tickets WHERE status = 'Escalated' AND priority IN ('High', 'Critical');
$$\Pi_{\text{ticket\_id}, \text{title}, \text{name}, \text{subscription\_tier}}(\text{Tickets} \bowtie \text{Customers})$$
SELECT t.ticket_id, t.title, c.name, c.subscription_tier FROM tickets t JOIN customers c ON t.customer_id = c.customer_id;
$$\Pi_{\text{ticket\_id}, \text{reason}, \text{to\_agent\_name}}(\text{Escalation\_Logs} \bowtie_{\text{to\_agent\_id}=\text{agent\_id}} \text{Agents})$$
SELECT el.ticket_id, el.reason, a.name AS to_agent FROM escalation_logs el JOIN agents a ON el.to_agent_id = a.agent_id;

DMGT Unit 2: Discrete Mathematical Proofs & Relations

Mathematical Verification
↻

1. Reflexivity

$$\forall a \in S, \ (a, a) \in R$$

Every support tier level $a$ possesses authority equal to or greater than itself. L1 ≤ L1, L2 ≤ L2.

✔ Verified True
⇄

2. Antisymmetry

$$(a, b) \in R \land (b, a) \in R \implies a = b$$

If Agent A escalates to Agent B and Agent B can escalate to Agent A, they must belong to the exact same tier. Mathematically eliminates cyclic deadlocks.

✔ Verified True
⇒

3. Transitivity

$$(a, b) \in R \land (b, c) \in R \implies (a, c) \in R$$

If L1 ≤ L2 and L2 ≤ L3, then L1 transitively possesses a valid escalation pathway to L3.

✔ Verified True

Polymorphic Hierarchy (Inheritance & Dynamic Dispatch)

public abstract class Agent {
    public abstract String resolveTicket(Ticket ticket);
}

public class L1SupportAgent extends Agent {
    @Override
    public String resolveTicket(Ticket t) {
        if (!"General".equals(t.getCategory())) {
            t.setStatus("Escalated"); // Polymorphic Escalation trigger!
            return "L1 cannot resolve specialized issue. Triggering Dijkstra.";
        }
    }
}

public class TechnicalLeadAgent extends Agent {
    @Override
    public String resolveTicket(Ticket t) {
        t.setStatus("Resolved");
        return "Applied cluster patch and resolved ticket.";
    }
}

Curriculum Alignment: Encapsulation guarantees state protection, Inheritance shares core agent queue fields, Polymorphism dynamically selects resolution logic at runtime, and Abstraction decouples the HelpdeskService API.
